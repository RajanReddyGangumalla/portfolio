# Your Name - Portfolio Website

A modern, responsive portfolio website built with HTML, CSS, and JavaScript. This portfolio showcases my skills, projects, education, and professional experience.

## 🚀 Features

- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Modern UI/UX**: Clean, professional design with smooth animations
- **Multiple Sections**: Home, Skills, Progress, Education, Projects, Certificates, Resume, and Contact
- **Interactive Elements**: Animated skill bars, timeline, and hover effects
- **SEO Optimized**: Proper meta tags and semantic HTML structure
- **Fast Loading**: Optimized CSS and minimal JavaScript

## 📁 Project Structure


## 📝 Customization Guide

### Personal Information

1. **Update Your Name**: Replace "Your Name" throughout all HTML files
2. **Contact Details**: Update email, phone, and social media links in all pages
3. **Professional Title**: Update the hero section titles and descriptions
4. **Social Links**: Replace placeholder URLs with your actual profiles

### Content Updates

1. **Skills**: Update skill names and proficiency levels in `skills.html`
2. **Projects**: Replace placeholder projects with your actual work
3. **Education**: Update your academic details in `education.html`
4. **Experience**: Modify work experience in `resume.html`
5. **Certificates**: Add your actual certifications in `certificates.html`

### Resume Files

1. Add your resume files to the `assets/` folder:
   - `resume.pdf` (recommended)
   - `resume.docx` (optional)
   - `resume.txt` (optional)

2. Update the download links in `resume.html` if you use different filenames

## 🎨 CSS Customization

The main styling is in `styles.css`. Key customization areas:

- **Colors**: Update the color scheme by modifying CSS variables
- **Fonts**: Change font families in the body selector
- **Spacing**: Adjust padding and margins throughout
- **Animations**: Modify transition durations and effects

## 📱 Responsive Breakpoints

The portfolio uses these breakpoints:
- **Desktop**: 1200px and above
- **Tablet**: 768px - 1199px
- **Mobile**: Below 768px

## 🚀 Deployment

### GitHub Pages

1. Push the code to a GitHub repository
2. Go to repository Settings → Pages
3. Select source as "Deploy from a branch"
4. Choose main branch and root folder
5. Your site will be available at `https://username.github.io/repository`

### Netlify

1. Connect your GitHub repository to Netlify
2. Set build command (if needed): `echo "No build needed"`
3. Set publish directory: `.` (root)
4. Deploy automatically on push

### Vercel

1. Import your GitHub repository
2. Vercel will detect it as a static site
3. Deploy with one click

## 🔧 Local Development

1. Clone the repository
2. Open the project folder in your code editor
3. Use Live Server extension or run:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js
   npx serve .
   
   # Using PHP
   php -S localhost:8000
   ```
4. Open `http://localhost:8000` in your browser
